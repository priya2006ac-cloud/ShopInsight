ShopInsight – E-commerce Data Analytics Dashboard

Project Overview

ShopInsight is a web-based e-commerce data analytics project that helps users understand sales performance, profit, customer activity, and business trends.

Objectives

- Analyze e-commerce sales and profit.
- Track key performance indicators (KPIs).
- Visualize monthly sales trends.
- Compare sales across product categories and regions.
- Explore sales forecasting using Python.

Technologies Used

- Python
- Flask
- PostgreSQL
- HTML, CSS, JavaScript
- Chart.js
- Pandas

Features

- Interactive analytics dashboard
- Total Sales, Total Profit, Total Orders, and Customers KPIs
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Data analysis and forecasting

Project Structure

- "app.py" – Flask application
- "forecasting.py" – Forecasting logic
- "templates/" – HTML templates
- "static/" – CSS and JavaScript files

How to Run

1. Install Python.
2. Install the required dependencies.
3. Configure your PostgreSQL database.
4. Run the Flask application using "python app.py".
5. Open "http://127.0.0.1:5000" in your browser.
